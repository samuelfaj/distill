# Distill packaging helpers

Private source packaging helpers for Distill by Samuel Fajreldines.
These packages are not a published npm distribution. Build and install from
this repository using the source installation instructions in README.en.md.

Grok, ChatGPT, OpenRouter, and local OpenAI-compatible models remain supported.
Provider login is optional when using a local model.
