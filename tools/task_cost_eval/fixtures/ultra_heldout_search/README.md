Contracts (no internal index layout is prescribed):
- documents.normalize(records) keeps its current validation and returns detached documents with id,title,body,tags,rating,archived. id is unique, tags are strings, rating is int (not bool), archived is bool. All text fields are strings. Preserve duplicate-id errors and input order. api.list_documents(records) returns normalized documents sorted by id, including archived.
- tokenizer.words(text) is already implemented: casefold, then runs of Unicode letters/digits excluding underscores using [^\W_]+. Preserve it. Thus 'Straße' and 'STRASSE' match; punctuation and underscores separate words. No stemming, stop words or substring matching.
- index.build(records) accepts raw valid documents and returns an index snapshot; caller mutations after build cannot change later search results. Count token occurrences with title weight 2 and body weight 1.
- search.search(index, query): each distinct query token must occur in the document (AND). Repeated query tokens count only once. Score is the sum of weighted occurrence counts for those distinct tokens. Return [{id,score}] sorted by score descending then id ascending. Empty or punctuation-only query matches all documents, score 0, sorted by id. Missing tokens match none.
- filters.select(records, tags=(), min_rating=None, include_archived=False): return detached normalized documents sorted by id. By default exclude archived; include_archived=True includes both active and archived. All requested tags must be present (case-sensitive exact strings, duplicate requested tags do not change results); min_rating, when given, is an inclusive integer bound, including negative values. Non-int/bool min_rating raises ValueError.
- api.query(records, text='', tags=(), min_rating=None, include_archived=False, offset=0, limit=None): apply search and filters, preserving search ranking, then paginate. Return {total: filtered count before pagination, hits: [documents with extra score field]}. offset and limit are nonnegative non-bool integers; limit=None is unbounded. Invalid bounds raise ValueError. offset beyond total or limit=0 yields empty hits, preserving total. Never mutate inputs; output documents and nested tags are detached. Results across calls must not share caller-owned state.
- CLI: python cli.py INPUT_JSON [--query TEXT] [--tag TAG ...] [--min-rating INT] [--include-archived] [--offset INT] [--limit INT]. Input is a JSON document list; output is query result JSON, exit 0. Invalid records/bounds or file errors exit 2 with stderr and no stdout. The existing unfiltered list_documents API is preserved.
