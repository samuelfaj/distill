# Project rules

- Python code targets Python 3.11+ and uses only the standard library unless a task says otherwise.
- Use four-space indentation and keep lines under 110 characters.
- Prefer small functions with clear names over comments that explain long ones.
- Put tests next to the code they cover, named `test_*.py`, runnable with `python3 -m unittest`.
- Run the tests closest to your change before saying you are done.
- Do not commit, push or create branches; leave changes in the working tree for review.
- The `team_notes` MCP server holds the team glossary; use it when a domain term is unclear.
