Implement layered application configuration in tools/task_cost_eval/fixtures/ultra_heldout_config. Add partial JSON and environment imports, recursive overlay with reset semantics, and deterministic JSON/environment exports. Wire them into api.resolve and CLI. Keep the default configuration and existing full validation behavior. Standard library only; edit the repository.

Public contracts:
- schema.defaults() returns a fresh independent {server:{host:'localhost',port:8080}, features:{debug:false,tags:['base']}, paths:{root:'.'}}. schema.validate(config) validates a COMPLETE configuration, returns None, rejects missing/unknown keys, wrong types and invalid values with ValueError. Preserve full validation. Host/root are nonempty strings equal to their stripped value, without CR/LF. Port is int, not bool, 1..65535. Debug is bool. Tags is a list of strings, each nonempty, stripped, without comma/CR/LF; preserve list order and duplicates, allow empty list.
- json_source.parse(text) returns a detached PARTIAL object: known keys only, nested partial sections allowed, supplied non-null leaves must satisfy the same validation rules. A null leaf means reset that key to its default; a null whole section means reset the entire section. Unknown keys, invalid values, non-object top-level JSON or malformed JSON raise ValueError. Empty object is valid.
- env_source.parse(mapping) returns a partial nested object from exact prefix APP__ and paths SERVER__HOST, SERVER__PORT, FEATURES__DEBUG, FEATURES__TAGS, PATHS__ROOT. Unrelated keys are ignored; any unknown APP__ path raises ValueError. Environment values must be strings. Strip host/root. Port accepts optional leading + and ASCII digits after strip; range as above. Debug accepts true/false ignoring case and surrounding whitespace, no other spelling. Tags splits commas, strips each member, drops empty members, empty string yields []. Environment cannot express null/reset. Do not mutate mapping.
- merge.overlay(base,patch) returns a detached complete object, recursing into partial sections. Leaves and lists replace, never append. Null resets the corresponding leaf or section to schema.defaults(), NOT to the previous layer. Reject unknown keys or invalid patch values with ValueError. Base is a valid complete configuration. Neither base nor patch may be mutated or retained by alias.
- api.resolve(json_texts=(), env=None): start from defaults, apply JSON texts in supplied order (later wins), then parsed env (highest precedence). None env is empty, never read process environment implicitly. Reset semantics work at any JSON layer. Return a full validated detached configuration; repeated calls do not share mutable defaults.
- export.render(config, format='json'): validate full config. 'json' returns json.dumps(config,sort_keys=True,separators=(',',':')) + '\n'. 'env' returns all five APP__ assignments sorted by full variable name, one NAME=value per line with a final newline; booleans lower true/false, port decimal, tags comma joined, strings verbatim. Unknown format raises ValueError. Imports of exported env/JSON reproduce the same values. No mutation.
- CLI: python cli.py [--json PATH ...] [--env PATH] [--format json|env]. --env file is a JSON object of environment-name/string-value pairs, passed explicitly (no OS environment). Print render result exactly once, exit 0. File/validation errors exit 2 with stderr and no stdout. Default invocation prints default JSON. Keep existing api.default_config() and CLI default JSON behavior.
